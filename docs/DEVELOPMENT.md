# 开发与验证

## 环境

- 扩展：主要在 Edge 验证，最低声明版本 116；Chrome 兼容性需按实际版本确认。
- 本地测试与演示：Node.js 22+，没有第三方 npm 依赖。
- 本地演示服务只监听 `127.0.0.1`，关闭运行它的终端进程即可停止服务。

## 自动检查

在仓库根目录运行：

```sh
npm test
npm run check
```

测试覆盖模型请求、答案解析、取消与异常、题库导入及复用、逐空返回格式、缺失资料处理，以及本地演示服务协议。所有模型响应均为测试内的预设值。演示服务测试会短暂绑定随机本机端口。

`check` 检查扩展入口、主要资源、HTML 控件 ID、版本、许可证以及明显的个人地址或密钥模式；它不是完整安全审计。

## 手动验证

1. 在扩展管理页加载本仓库的 `extension/`。已有日常安装的用户可使用单独的浏览器测试配置，避免混淆存储。
2. 运行 `npm run demo`，打开 `http://127.0.0.1:8765/`。
3. 题伴 API 地址设为 `http://127.0.0.1:8765/v1`，模型 ID 为 `demo`，密钥留空，保存设置。
4. 点击“开始读取此页面”，确认能读到当前题干与选项。
5. 开始自动答题，预期单选 B、多选 A/C，最后两个空依次为 5、6。
6. 确认页面下方的实际答案记录，以及最后一题没有被自动提交；可手动点击演示提交按钮。
7. 另行检查暂停/取消、重新读取和侧栏开关。真实平台测试应在允许使用辅助工具的练习环境进行。

演示服务只接受已知合成题目，未知请求会返回错误，不会转发到任何模型。它不包含真实题库、账号、API Key 或课程资源，也不验证图片识别和真实平台适配。

## 证据范围

源项目 1.6.31 的 252 项记录包含历史离线页面检查；本仓库没有直接复制那些依赖开发目录的全部用例。请以当前命令输出作为本仓库测试数量，不把历史总数当作当前 CI 结果。

发布包应包含 `extension/` 里的运行文件、README、LICENSE 和第三方通知，不打包 Git 历史、个人设置、测试运行日志或本机浏览器资料。
