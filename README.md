# 题伴 · 浏览器答题助手

在浏览器侧栏读取网页题目，结合文字与必要截图生成参考答案，并可按需自动填写。

**当前版本：1.6.32 · 项目阶段：早期可用 · 重点适配：学习通、智慧树网页版**

题伴是一款采用 Manifest V3 的浏览器扩展。它把题目读取、模型解答、网页填写和进度展示放在同一个侧栏中，支持只看参考答案，也支持对已识别的控件填写并进入下一题。最终提交由用户手动完成。

截至 2026-10-30，项目维护者反馈：学习通和智慧树已基本能够正常使用。具体兼容性仍取决于课程页面、题型和平台版本，尚无覆盖所有网站的实测结论。

## 功能

- **文字与截图结合读取**：完整、可读的结构化文字题优先使用网页文字；需要图像、表格或视觉信息时，按条件使用文字加截图或截图识别。图片输入需要对应的模型能力和浏览器授权。
- **侧栏参考解答**：显示当前题目、答案和解题说明；支持手动修正题目文字与重新解答。
- **可选自动填写**：选择题按模型返回的选项字母操作；填空题按输入框顺序填写逐空答案。当前流程不因模型的“不确定”标记单独暂停，也不增加模型与网页题干、选项文字的逐字匹配步骤。
- **必要的中断处理**：识别到题目资料缺失、实际换题、无法对应控件或填写未保留等情况时停止后续动作；用户可暂停或取消。
- **已加载题目概览**：展示当前能识别的题目摘要、本次已解答数量和已自动填写数量；可重新扫描。
- **题目区域截图**：支持手动选区，以及已适配场景中的长题分段截图、滚动定位和固定浮层避让。
- **网站适配**：支持常见原生控件、ARIA 选择控件及部分组件库结构；可配置网站选择器，并对新的选择题结构尝试模型辅助适配。
- **本地导入题库**：支持外部 JSON 题库导入、查看、修正和导出。新题与模型生成的答案不会自动加入题库。

题库复用仍会匹配题干和整组选项；这与自动填写时关闭模型题干、选项文字核对是两套不同流程。

## 支持范围

| 题目或页面 | 当前范围 |
|---|---|
| 单选、多选、判断 | 已有读取、解答与自动填写流程；目标网页控件需要能被识别 |
| 普通单空、多空填空 | 支持已识别输入框的逐空填写 |
| 学习通富文本填空 | 已处理部分 UEditor 预览、编辑和保存结构；其他编辑器版本需要验证 |
| 图片、表格、公式题 | 支持已覆盖的文字与截图输入；解答能力取决于模型，自动填写仍取决于网页控件 |
| 多层同源内嵌题页 | 已有读取、坐标、滚动和截图处理，扫描存在数量上限 |
| 新网站的选择题 | 可尝试通用规则、手动网站适配或模型辅助适配，兼容性需验证 |
| 简答、论述题 | 可在取得完整题目后请求参考答案，尚无通用自动填写支持 |
| 下拉、排序、连线、拖拽 | 尚无通用自动操作支持 |
| 跨来源内嵌题页 | 尚未实现子页面独立注入与通信 |
| 手机 App、独立桌面软件 | 当前浏览器扩展不直接操作这些应用中的控件 |

完整读取题目、模型回答正确、网页实际保存答案需要分别验证。页面控件显示选中，不代表答案已经由平台判定正确。

## 安装

建议先使用 Microsoft Edge 116 或更新版本。项目采用 Chromium 扩展 API；Chrome 116 或更新版本可尝试加载，但尚未单独完成与 Edge 同等范围的验证。

1. 下载源码或扩展压缩包并解压。源码加载仓库中的 `extension/` 目录；发行包加载其中包含 `manifest.json` 的目录。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启“开发人员模式”，选择“加载解压缩的扩展”，加载上述目录。
4. 打开测验网页，通过工具栏的题伴图标打开侧栏。
5. 在设置中填写自己的 API 地址、模型 ID 和 API Key，保存并测试连接。

扩展采用普通 JavaScript、HTML 和 CSS，当前扩展运行目录无需前端构建即可加载。模型接口需要用户自行配置，服务商可能按调用计费。

本地 HTML 文件还需要在扩展详情中允许访问文件 URL。更新现有安装时，建议保留原加载目录，重新加载扩展、刷新题页并重开侧栏。

## 模型配置

模型调用使用 OpenAI 兼容的 Chat Completions 请求格式。接口地址、模型名称、图片输入和服务商附加参数仍需与实际服务匹配，不能仅凭“兼容接口”认定所有能力都可用。

| 设置 | 说明 |
|---|---|
| API 地址 | 填写你有权使用的服务地址，例如 `https://your-provider.example/v1`；该地址仅为格式示例 |
| 模型 ID | 填写服务商提供的准确模型名称 |
| API Key | 填写自己的接口密钥；部分本地服务可不使用密钥 |
| 按需截图识题 | 需要支持图片输入的模型及对应浏览器授权 |

公开版的 API 地址、模型 ID 和密钥默认为空，使用前需要自行配置。也可按下文运行无需密钥的本地演示服务。

当前普通解题请求超时为 90 秒。特定阿里云 DeepSeek V4 配置保留思考参数；其他服务商不会自动获得相同参数支持。

## 使用

### 查看参考答案

1. 打开题目页面，点击“开始读取此页面”。
2. 查看题目文字、来源标签和已识别题目数量。
3. 按设置自动解答，或点击“解答当前题”。
4. 使用页面操作或侧栏的上一题、下一题读取功能继续查看；答案由自己填写。

### 自动填写

1. 打开已经确认兼容的题页，点击“开始自动答题”。
2. 题伴逐题重新读取、请求答案、填写并继续下一题。题目概览用于展示，不会把扫描时的旧控件引用一直用到后续题目。
3. 遇到缺少资料、无法填写或页面实际变化等情况时，按提示处理后继续。
4. 最后检查网页实际保留的答案，手动完成保存和最终提交。

选择题按网页显示字母映射，多空填空按输入框顺序对应。自动填写不会证明答案正确；题目相关图片或材料缺失时不会凭猜测继续。

当前进度只覆盖本次连接，尚未提供跨刷新、跨浏览器重启的断点恢复。分页或懒加载页面中的“已识别题目数”不等于整卷总题数。

## 数据与权限

| 数据或权限 | 用途与边界 |
|---|---|
| 题目文字、必要截图 | 解答时发送给用户配置的模型服务；截图可能包含题目周边可见内容 |
| 自动适配结构摘要 | 启用该功能且需要适配时，发送当前候选结构信息给同一配置的模型服务；可能额外产生模型调用 |
| API Key | 保存在本机扩展存储，作为凭据发送给配置的模型接口；本机保存不等于已实现应用层加密 |
| 导入题库、网站设置、学习到的适配规则 | 保存在本机扩展存储 |
| `activeTab`、`scripting`、`tabs` | 绑定当前题页、注入读取脚本及管理相关标签页状态 |
| `sidePanel`、`storage` | 显示侧栏及保存本机设置 |
| 可选网站权限 | 访问题页与模型服务。当前启用截图识别时会请求较广的 `<all_urls>` 权限；截图操作绑定当前测验标签页 |

模型服务如何保存或使用请求数据，取决于所选服务商。公开反馈问题前，请检查诊断文本和截图中的个人信息、课程信息、题目内容及网页地址。

## 实现结构

以下为当前扩展运行目录中的主要文件：

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 扩展入口、权限与侧栏配置 |
| `background.js` | 侧栏行为、页面绑定与连接断开后的停止处理 |
| `content.js` | 题目读取、字体还原、控件识别、截图定位、填写与翻题 |
| `core.mjs` | 模型请求、配置验证、输出解析与错误处理 |
| `bank.mjs` | 导入题库的数据与查询逻辑 |
| `sidepanel.html` / `sidepanel.css` | 侧栏界面与样式 |
| `sidepanel.js` | 配置、题目展示、解答任务与自动填写调度 |
| `THIRD_PARTY_NOTICES.md` | 已集成第三方代码和数据的来源与许可证声明 |

文字与截图的选择在本地完成，不会为了决定输入方式单独增加一次模型请求。新选择题结构的自动适配可能产生额外请求。

## 本地演示与开发

需要 Node.js 22 或更新版本，无需安装 npm 依赖。

```sh
npm test
npm run check
npm run demo
```

演示启动后，打开 `http://127.0.0.1:8765/`，加载本仓库的扩展。在题伴设置中填写 API 地址 `http://127.0.0.1:8765/v1`、模型 ID `demo`，API Key 留空。页面含单选、多选和双空填空三个合成题目，服务只返回对应的预设答案，不调用外部模型、不收费。

可先检查读取，再开始自动填写。预期依次为单选 B、多选 A/C、两个填空 5 和 6；最终提交仍需手动。这个演示验证流程，不衡量模型解题准确率。详见 [开发与验证说明](docs/DEVELOPMENT.md)。
